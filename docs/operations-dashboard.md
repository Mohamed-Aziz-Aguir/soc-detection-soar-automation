# Operations Dashboard (Mock-up)

The SOC Operations dashboard is a UI mock-up used for portfolio demonstration:
- Centralized view of SOC operations (cases, alerts, workflows, response time)
- Tool health visibility (connected/disconnected + uptime + activity counters)
- Intended audience: analysts + SOC lead/manager
