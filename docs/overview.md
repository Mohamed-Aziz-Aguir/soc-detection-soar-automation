# Overview

SOC Operations Center is an academic project that simulates a realistic internal SOC with:
- SIEM detections (Wazuh)
- Orchestration/automation (Shuffle)
- Case management (TheHive: Alert → Case)
- Automated enrichment (Cortex)
- Threat intelligence correlation (MISP)
- Conditional response paths (pfSense / Active Directory / Velociraptor)
- SOC notifications (Discord + Slack)
- Operations dashboard UI (mock-up) for visibility and metrics

The primary objective is to demonstrate **SOC engineering** skills: detection design, incident handling, automation logic, enrichment, response policy, and operational metrics.
