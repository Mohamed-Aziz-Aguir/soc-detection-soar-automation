# SOC Operations Dashboard (Mock-up)

## Purpose
This dashboard was developed as a **visualization and operational awareness layer** for SOC operations. It demonstrates how incidents, alerts, workflows, and tool health could be presented to analysts and SOC managers.

> **Important:** The dashboard UI shown in screenshots is a **mock-up** used for demonstration/portfolio purposes. Metrics and statuses displayed are simulated and not connected to a live production backend.

## What it demonstrates
- SOC-style incident and case tracking interface (severity, status, assignee)
- Visualization of running workflows and alert volume
- Tool health view (connected/disconnected, uptime, key counters)
- Analyst-friendly UX and SOC KPI framing (e.g., average response time)
